# Weather Dashboard

Dashboard climático responsivo desenvolvido com React.

## Funcionalidades:

* Busca por cidades
* Previsão atual
* Previsão por hora
* Previsão do dia seguinte
* Conversão °C / °F
* Histórico de cidades pesquisadas
* Persistência com localStorage

## Tecnologias:

* React
* Vite
* CSS
* OpenWeather API

## Aprendizados:

* Componentização
* Consumo de API
* useEffect
* Gerenciamento de estado
* Persistência local
* Tratamento de erros
